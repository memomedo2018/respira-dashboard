# RespiraTech PHP Backend Scaffold

This is the staged Hostinger PHP backend that will replace the Railway Python API.

Do not deploy it as the live `/api` until the migration checklist in
`docs/RESPIRATECH_PHP_BACKEND_MIGRATION_PLAN.md` is complete.

Initial scope:

- Health endpoint
- Store JSON read/save
- Blog JSON read/save/toggle/delete
- Base64 image upload
- Dashboard config read
- CORS/admin helpers compatible with the current dashboard

Pending:

- Static build replacement
- OpenAI generation
- SEO Brain
- Google Search Console
- Hostinger cron scripts
